# Game page: tracker and action bar (v67)

On the session page: a Plan · Play · Pay · Done tracker (`trackerHtml(sessionStep(s))`) above the tabs, and a fixed action bar for the next step. Play: Live score + Add game score (only people who can add games). Pay: Pay + the amount I owe (opens My payments). Done / nothing owed / editing / Games tab: no bar. The old "Add game score" button between the tabs is replaced by this bar.
No data change. The Overview / Players / Games / Bill tab split from the prototype is not done: the page keeps its two tabs (Bill, Games) and the players stay in the bill.
**Version:** v67.
