# Poll card in the new look (v74)

Follows the prototype's Plan screen. Card: date block + court (map link) + time + joined count + status pill; creator as a person (photo + name); tracker bar; **vote bar** (in / out, need N); deadline; answers with voters (photo + name); buttons. The old "Joined players" box is removed (the same people already show under the first answer). The Active | History switch uses the app's tab style (`dashboard-tabs`). Same data, same voting code.
**Version:** v74.
